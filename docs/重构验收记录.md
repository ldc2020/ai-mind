## 修复的具体问题

1. 保存失败也可能清除未保存标记。
2. 首次保存提交的正文被新建接口忽略，导入文档可能保存成默认模板。
3. 库导出方法返回 Promise/数据 URL，旧代码却当作带 png()/svg() 方法的对象。
4. 自定义主题名传给库后退回 default，导致主题不能正确保存恢复。
5. XMind JSON 工作表数组无法被后端旧转换器解析。
6. 无效目标文件夹导致条目被静默移动到根目录。
7. 浮动节点坐标 0 和边框宽度 0 被默认值覆盖。
